# Transcriber — контекст для агентов

Сервис: обрезка аудио в браузере → Whisper (STT) → LLM-постобработка → доставка в Telegram / внешнюю ручку. Оркестрация — встроенным воркером (`direct`) либо в n8n (`n8n`), переключается `PIPELINE_MODE`.

## Раскладка

| Путь | Что там |
|---|---|
| `frontend/` | Статика **без сборщика**. ES-модули, зависимости вендорятся в `frontend/vendor/`. Не вводить npm/Vite без явной необходимости |
| `backend/app/` | FastAPI (`main.py`) + arq-воркер (`worker.py`). Конвейер — `pipeline.py`, клиенты — `asr.py`, `llm.py`, `delivery.py`, промпты — `prompts.py` |
| `n8n/workflows/` | Экспортированные workflow. Правки в UI выгружать обратно: `n8n export:workflow --all --separate --output=/workflows` |
| `docs/` | Пользовательские инструкции. При изменении поведения обновлять соответствующий файл |
| `deploy/` | nginx (dev) и Caddy (prod) |

## Правила

* Внешние сервисы вызывать только через OpenAI-совместимый контракт — это позволяет менять ASR/LLM без правок кода.
* Всё, что конфигурируется, идёт через `.env` и `config.py`; хардкод адресов и токенов недопустим.
* Файл пользователя удаляется в `finally` конвейера — не убирать.
* Ответы UI и документация — на русском. Идентификаторы, ключи API и имена узлов n8n — как есть.
* Изменили контракт `/api/v1` — синхронно обновите `docs/06-api.md` и `frontend/assets/api.js`.
